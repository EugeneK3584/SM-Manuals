### Обновленный и объединённый анализ Smart Money Concept (SMC) для функционального дизайна

#### **1. Расширенная терминология SMC (интеграция новых данных)**

| Термин | Определение | Источник | Важность |
|--------|-------------|----------|----------|
| **Structure Mapping** | Маркировка HH/HL (бычий) или LH/LL (медвежий) с подтверждением BOS/ChoCh закрытием свечи | Все методички | Высокая (основа) |
| **Imbalance (FVG)** | Ценовой разрыв между high/low соседних свечей, требующий заполнения | ICT Core | Высокая (POI) |
| **Order Block (OB)** | Свеча входа "умных денег" с критериями:<br>- Liquidity sweep до формирования<br>- Наличие FVG после<br>- Подтверждение структуры | Стратегия SMC | Высокая (основной вход) |
| **Breaker Block (BB)** | Пробитый OB с импульсным пробоем и ретестом | Стратегия SMC | Средняя (доп. вход) |
| **Rejection Block (RJB)** | Свеча с тенью >60% диапазона и телом <30% | Стратегия SMC | Средняя (доп. вход) |
| **IFC** | Institutional Funding Candle - свеча взятия ликвидности на major swing | Новые методички | Высокая (подтверждение) |
| **Retail Liquidity Trap** | Зоны, где розничные трейдеры размещают стопы (трендовые линии, S/R) | Новые методички | Критическая (фильтр) |
| **Session Liquidity** | Asian/London/NY Session Highs/Lows как магниты | Новые методички | Высокая (POI) |
| **Flip Entry** | Смена спроса/предложения (Demand->Supply) с переходом на LTF | Новые методички | Высокая (стратегия) |
| **Smart Money Trap** | Ложный OB, созданный для провокации розничных трейдеров | Новые методички | Критическая (фильтр) |
| **Single Candle Mitigation** | Вход на sweeping liquidity с LTF подтверждением | Новые методички | Средняя (оптим. входа) |

#### **2. Объединённый алгоритм сетапов (полная интеграция)**

```plaintext
1. Тренд и структура (HTF: D1/W1)
   ├─ Бычий: HH + HL + подтвержденный BOS
   ├─ Медвежий: LH + LL + подтвержденный BOS
   └─ Консолидация: не торговать

2. Поиск POI (Points of Interest)
   ├─ Session Highs/Lows (Asian, London, NY)
   ├─ Предыдущие Daily Highs/Lows
   ├─ Ключевые Swing Points
   ├─ FVG (на HTF и LTF)
   └─ Volume Profile POC/VAH/VAL (опционально)

3. Валидация блоков в POI
   ├─ Order Block (OB):
   │  ├─ Связь с FVG
   │  ├─ Предшествующий liquidity sweep
   │  └─ Объем >150% среднего
   ├─ Breaker Block (BB):
   │  ├─ Импульсный пробой уровня
   │  └─ Разворот + ретест
   └─ Фильтры:
      ├─ Проверка на Smart Money Trap (ожидание inducement/sweep)
      ├─ Исключение Retail Liquidity Trap (зоны ТА)

4. Подтверждение на LTF
   ├─ Для Forex: M15 -> M1/M2
   ├─ Для Crypto: H1 -> M5
   ├─ Сигналы:
   │  ├─ Свечные паттерны (поглощение, пин-бар)
   │  ├─ FVG в направлении тренда
   │  ├─ ChoCh
   │  └─ IFC на ключевых уровнях

5. Выбор стратегии входа
   ├─ Flip Entry:
   │  ├─ Касание HTF Supply/Demand
   │  ├─ Переход на LTF
   │  ├─ Ожидание ChoCh + pullback к OB
   ├─ Single Candle Mitigation:
   │  ├─ Вход на sweeping major high/low
   │  ├─ Tap на LTF POI
   └─ Классический вход:
      ├─ Лонг: Discount + бычий OB/RJB
      ├─ Шорт: Premium + медвежий OB/RJB

6. Управление позицией
   ├─ Стоп-лосс:
   │  ├─ За экстремумом блока (OB/BB)
   │  └─ За тенью (RJB)
   ├─ Тейк-профит:
   │  ├─ EQH/EQL (ближайшая ликвидность)
   │  ├─ POC (Volume Profile)
   │  └─ R/R минимум 1:2
   └─ Частичное закрытие:
      ├─ 50% позиции при достижении 1:1 R/R
```

#### **3. Детализация стратегий входа**

**Flip Entry Process (HTF -> LTF):**
1. Касание цены HTF Supply/Demand зоны
2. Переход на LTF (M1/M5 для Forex, M5/M15 для Crypto)
3. Ожидание ChoCh (смена структуры на LTF)
4. Pullback к Order Block
5. Вход при подтверждении (свечной паттерн, FVG)

**Single Candle Mitigation:**
- Триггер: Sweep major high/low (взятие ликвидности)
- Подтверждение: Tap на LTF POI (FVG, OB)
- Вход: На закрытии свечи, снявшей ликвидность
- Управление: Множественные добавления в прибыль

**Session Liquidity Rules:**
- **Asian Session (00:00-08:00 GMT):**
  - Low -> ликвидность для buy
  - High -> ликвидность для sell
- **London Session (08:00-16:00 GMT):** 
  - Продолжение тренда Asian
- **New York Session (13:00-21:00 GMT):**
  - Если Asian Low взят -> разворот вверх
  - Если Asian High взят -> продолжение тренда

### Заключение для функционального дизайна

1. **Ядро алгоритма**:
   - Мультитаймфреймовый анализ (HTF для тренда, LTF для входа)
   - Приоритет Session/Daily Liquidity как POI
   - Строгая валидация блоков (OB/BB/RJB) через FVG и объем

2. **Критические фильтры**:
   - Retail Liquidity Trap: запрет входа в зонах ТА (трендовые линии, S/R)
   - Smart Money Trap: ожидание inducement/sweep перед входом в OB

3. **Стратегии входа**:
   - Flip Entry для разворотов
   - Single Candle Mitigation для агрессивных входов
   - Классический вход в OTE

4. **Управление позицией**:
   - Динамический расчет стоп-лосса (экстремум блока/тени)
   - Тейк-профит до ближайшей ликвидности
   - Обязательное частичное закрытие

Для реализации в PineScript потребуются:
- Детектор структуры (Swing Points, BOS/ChoCh)
- Индикатор Session/Daily Liquidity
- Модуль валидации OB/BB/RJB
- Сигналы Flip Entry и Mitigation
