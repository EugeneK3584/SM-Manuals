#### **1. Сравнение терминов и выявление общих моментов**

| Термин | Первое описание | Второе описание | Общие моменты | Различия/Уточнения |
|--------|-----------------|-----------------|--------------|-------------------|
| **Структура рынка** | HH/HL (восходящая), LH/LL (нисходящая), майнер-структура | HH+HL (восходящая), LH+LL (нисходящая), консолидация (Range) | Базовая структура через экстремумы | Второе добавляет консолидацию и детализирует Swing Points (3 свечи) |
| **Ликвидность** | Внешняя (за экстремумами), внутренняя (внутри движения), SSL/BSL | EQH/EQL, Swing Points, границы Range, Stop Hunt | Зоны скопления ордеров как цели манипуляции | Второе конкретизирует типы (EQH/EQL) и связывает с визуальными фигурами ТА |
| **Order Block (OB)** | Свеча перед импульсом со снятием ликвидности и поглощением | Свеча с крупным объемом после снятия ликвидности | Зона входа "умных денег" | Второе добавляет критерий объема и связь с имбалансом |
| **Breaker Block (BB)** | Пробитый OB с импульсным пробоем и ретестом | Свеча, сломавшая структуру и развернувшаяся | Пробитый уровень, меняющий роль | Второе допускает BB как сигнал продолжения тренда |
| **Rejection Block (RJB)** | OB с длинной тенью (>60%) и малым телом (<30%) | Свеча с длинной тенью, указывающая на отторжение | Свеча с длинной тенью как сигнал разворота | Первое дает количественные критерии, второе связывает с OB |
| **FVG (Fair Value Gap)** | Разрыв между 1-й и 3-й свечой импульса после снятия ликвидности | Ценовой разрыв (дисбаланс) с целью заполнения 50-100% | Ценовой разрыв как зона возврата цены | Первое требует снятия ликвидности перед формированием |
| **Premium/Discount** | Зоны выше/ниже 0.5 по Фибоначчи, OTE: 0.62-0.79 | Premium >50%, Discount <50%, OTE: 62-79% | Полное совпадение зон и OTE | Нет различий |
| **Sponsored Candles** | Свечи с объемом >150% и телом >200% от среднего | Не упоминается, но есть Stop Hunt | Аномальные свечи как действия "умных денег" | Первое дает количественные критерии |
| **STB/BTS** | Манипуляция: продажа→покупка (STB), покупка→продажа (BTS) | STB: снятие ликвидности вверх→разворот вниз, BTS обратно | Полное совпадение алгоритма | Нет различий |

#### **2. Выявление различий и спорных моментов**

| Тема | Первое описание | Второе описание | Спорный момент | Рекомендуемое решение |
|------|-----------------|-----------------|----------------|----------------------|
| **BoS vs ChoCH** | Четкое разделение: ChoCH - смена, BoS - продолжение | Путаница: "BoS = ChoCH – да это одно и тоже!" | Двойная трактовка BoS | Четко разделять: ChoCH - разворот, BoS - продолжение |
| **Mitigation Block** | Не упоминается | Назван слабым инструментом с низкой отработкой | Противоречивость инструмента | Исключить из основного алгоритма как ненадежный |
| **Точка входа по OB** | Тело OB или экстремум тени, консервативный вход на MTF | Агрессивный вход от экстремума, консервативный на младшем ТФ | Отсутствие единого подхода | Использовать консервативный подход с подтверждением |
| **Фибо-уровни для OTE** | OTE: 0.62-0.79 | В одних методичках 0.705, в других 0.618-0.786 | Разные числовые значения | Использовать диапазон 0.618-0.786 с акцентом на 0.705 для индексов |
| **Volume Profile** | Не упоминается | POC/VAH/VAL - ключевые уровни | Отсутствие интеграции с другими инструментами | Добавить как дополнительный инструмент подтверждения |

#### **3. Объединенный алгоритм построения сетапов**

```plaintext
┌─────────────────────────────────────────────────────────────┐
│  ОБОБЩЕННЫЙ АЛГОРИТМ SMC НА ОСНОВЕ ВСЕХ МЕТОДИК            │
├─────────────────────────────────────────────────────────────┤
│  Шаг 1: Определение тренда (старший ТФ: D1/W1)            │
│    ├─ Восходящий: HH + HL                                   │
│    ├─ Нисходящий: LH + LL                                   │
│    └─ Консолидация: избегать торговли                        │
│                                                             │
│  Шаг 2: Построение коррекции и зон OTE                       │
│    ├─ Сетка Фибоначчи от последнего импульса                 │
│    ├─ Discount: 0-50% (для лонгов)                          │
│    ├─ Premium: 50-100% (для шортов)                         │
│    └─ OTE: 62-79% (оптимальная зона входа)                   │
│                                                             │
│  Шаг 3: Поиск блоков в OTE                                  │
│    ├─ Order Block (OB):                                     │
│    │  ├─ Объем >150% среднего                               │
│    │  ├─ После снятия ликвидности (пробой экстремума)      │
│    │  ├─ В направлении тренда                               │
│    │  └─ С имбалансом (FVG) после                          │
│    ├─ Breaker Block (BB):                                   │
│    │  ├─ Пробитый OB/уровень                                │
│    │  ├─ Импульсный пробой                                  │
│    │  ├─ Разворот после пробоя                               │
│    │  └─ Ретест для входа                                   │
│    └─ Rejection Block (RJB):                                │
│       ├─ Тень >60% диапазона                                 │
│       ├─ Тело <30% диапазона                                 │
│       ├─ Подтверждение объема                               │
│       └─ Часто формируется у OB                             │
│                                                             │
│  Шаг 4: Подтверждение на младшем ТФ (M5/M15)                │
│    ├─ FVG в направлении тренда                               │
│    ├─ Свечной паттерн (поглощение, пин-бар)                 │
│    ├─ BoS (только в направлении тренда)                     │
│    └─ Volume Profile (POC/VAH/VAL) - опционально           │
│                                                             │
│  Шаг 5: Вход                                                │
│    ├─ Лонг: Discount + бычий OB/RJB + подтверждение          │
│    ├─ Шорт: Premium + медвежий OB/RJB + подтверждение        │
│    └─ BB: вход на ретесте блока                            │
│                                                             │
│  Шаг 6: Стоп-лосс                                          │
│    ├─ За экстремумом блока (OB, BB)                         │
│    └─ За тенью (RJB)                                        │
│                                                             │
│  Шаг 7: Тейк-профит                                         │
│    ├─ Ближайшая ликвидность (EQH/EQL)                        │
│    ├─ POC (Volume Profile) - опционально                     │
│    └─ R/R 1:2                                              │
│                                                             │
│  Шаг 8: Фильтры                                            │
│    ├─ Избегать консолидации                                 │
│    ├─ Торговать в "макросы" (15:15-15:45 NYT)               │
│    └─ Учитывать время сессии                                │
└─────────────────────────────────────────────────────────────┘
```

#### **4. Детализация ключевых сетапов**

##### **4.1. Сетап: Вход от Order Block в OTE**
```
┌─────────────────────────────────────────────────────────────┐
│  СЕТАП: ORDER BLOCK В OTE                                   │
├─────────────────────────────────────────────────────────────┤
│  Условия:                                                  │
│  ├─ Тренд определен на старшем ТФ                           │
│  ├─ Цена в зоне OTE (62-79% коррекции)                      │
│  ├─ Найден OB с объемом >150% среднего                     │
│  ├─ OB после снятия ликвидности                             │
│  └─ Есть FVG после OB                                      │
│                                                             │
│  Вход:                                                     │
│  ├─ Консервативный: ретест OB на младшем ТФ                │
│  ├─ Агрессивный: от тела OB                               │
│  └─ Подтверждение: свечной паттерн или FVG                 │
│                                                             │
│  Стоп-лосс:                                               │
│  ├─ За экстремумом OB                                     │
│                                                             │
│  Тейк-профит:                                             │
│  ├─ Ближайшая ликвидность (EQH/EQL)                        │
│  ├─ POC (Volume Profile)                                   │
│  └─ R/R 1:2                                              │
└─────────────────────────────────────────────────────────────┘
```

##### **4.2. Сетап: Вход от Breaker Block**
```
┌─────────────────────────────────────────────────────────────┐
│  СЕТАП: BREAKER BLOCK                                       │
├─────────────────────────────────────────────────────────────┤
│  Условия:                                                  │
│  ├─ Тренд определен на старшем ТФ                           │
│  ├─ Найден пробитый OB/уровень                             │
│  ├─ Пробой был импульсным                                  │
│  ├─ После пробоя был разворот                              │
│  └─ Цена вернулась к BB (ретест)                           │
│                                                             │
│  Вход:                                                     │
│  ├─ На ретесте BB                                         │
│  └─ Подтверждение: объем, свечной паттерн                   │
│                                                             │
│  Стоп-лосс:                                               │
│  ├─ За экстремумом BB                                     │
│                                                             │
│  Тейк-профит:                                             │
│  ├─ В направлении тренда                                   │
│  ├─ До следующей ликвидности                              │
│  └─ R/R 1:2.5 (выше из-за надежности паттерна)             │
└─────────────────────────────────────────────────────────────┘
```

### **Заключение**

Объединенный анализ методичек показал высокую степень соответствия концепций Smart Money, но выявил несколько ключевых различий:

1. **Четкое разделение ChoCH и BoS**: Необходимо строго разделять эти понятия для избежания путаницы.
2. **Количественные критерии**: Второе описание добавляет конкретные цифры для объема и размеров свечей.
3. **Мульти-таймфреймный подход**: Оба описания подчеркивают важность анализа на нескольких ТФ.
4. **Volume Profile**: Второе описание вводит этот инструмент как дополнительное подтверждение.

**Рекомендуемый алгоритм** объединяет лучшие практики из обоих источников:
- Четкое определение тренда на старшем ТФ
- Построение сетки Фибоначчи с выделением OTE-зон
- Поиск блоков (OB, BB, RJB) в OTE-зонах
- Подтверждение на младшем ТФ
- Строгое управление рисками
